# 😎 **Sobre mim:**

Sou Desenvolvedor Fullstack, com graduação em Física pela Universidade Federal do Acre 🧑🏼‍🎓
e pós-graduação em Engenharia de Software pela PUC Minas 🎓.
Atuo do banco de dados à interface, construindo APIs escaláveis e interfaces consistentes
para sistemas com regras de negócio complexas e alto volume de dados.

Minha trajetória começou na Física, motivada pela curiosidade pelo universo científico.
Foi essa mesma curiosidade que me levou à tecnologia: comecei estudando por conta própria
JS, Java e C#, e não parei mais. Hoje atuo com Node.js, NestJS, React e TypeScript,
já tendo passado por projetos com inteligência artificial, geolocalização em tempo real
e integrações em nuvem.
